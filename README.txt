HARIRA SPOGMAY — PROFESSIONAL PORTFOLIO
=======================================

PREVIEW ON YOUR WINDOWS LAPTOP
1. Download Harira_Spogmay_Professional_Portfolio.zip.
2. Right-click the ZIP file and choose "Extract All".
3. Open the extracted folder.
4. Double-click index.html. It should open in Chrome or your default browser.
5. Keep the assets folder, index.html, style.css and script.js together. Do not move index.html alone.

WHAT IS INCLUDED
- Responsive portfolio website
- Your LinkedIn profile link
- Profile portrait cropped from the screenshot you supplied
- Five certificate images, including OPSWAT Cybersecurity Fundamentals Associate
- About, Skills, Projects, Certificates and Contact sections
- Certificate click-to-enlarge gallery
- Mobile navigation and responsive layouts

BEFORE PUBLISHING
- In index.html, replace https://github.com/ in the project card with the exact URL of your Women's Education and Employment Analysis repository.
- If you want to show an email address, add your preferred public contact email in the Contact section.
- Add any extra certificates to assets/certificates and duplicate/edit one certificate-card block in index.html.
- The project summary is a short description based on the project title you previously shared. Review it and adjust to match your actual work.

PUBLISHING ONLINE
You can publish this site using GitHub Pages. First preview it locally. Then create a GitHub repository, upload the files/folders, and enable Pages in repository Settings. Keep the folder structure unchanged.
